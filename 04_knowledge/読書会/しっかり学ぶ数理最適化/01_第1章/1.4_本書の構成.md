# 1.4 本書の構成

← [[1.3_代表的な最適化問題]] | ↑ [[しっかり学ぶ数理最適化_MOC]] | → [[1.5_まとめ]]

## 本書で紹介する最適化問題とアルゴリズム（図1.8）

図1.8は「連続最適化問題」「離散最適化問題（組合せ最適化問題）」の2つの根から、問題クラスとそれに対応するアルゴリズムを矢印で結んだ樹形図。

**連続最適化問題**

| 問題 | アルゴリズム |
|------|-------------|
| 線形計画問題 | 単体法 |
| 凸2次計画問題 | 有効制約法 |
| 制約なし非線形計画問題 | 最急降下法、ニュートン法、準ニュートン法 |
| 制約つき非線形計画問題 | ペナルティ関数法、拡張ラグランジュ関数法、内点法、逐次2次計画法 |

**離散最適化問題（組合せ最適化問題）**

| 問題 | アルゴリズム |
|------|-------------|
| 資源配分問題、最小全域木問題など | 貪欲法 |
| 資源配分問題、ナップサック問題、最小費用弾性マッチング問題など | 動的計画法 |
| 最短路問題 | ダイクストラ法、ベルマン・フォード法、フロイド・ウォーシャル法 |
| 最大流問題、最小費用流問題、最大マッチング問題、割当問題など | 増加路法、負閉路消去法、最短路繰り返し法 |
| 整数計画問題 | 分枝限定法、切除平面法 |
| ビンパッキング問題、最大カット問題、巡回セールスマン問題、頂点被覆問題、ナップサック問題など | 性能保証付き近似解法 |
| さまざまなNP困難問題 | 局所探索法、メタヒューリスティクス |

## 各章の概要

### 2章 線形計画
- 線形計画問題はもっとも基本的な最適化問題。大規模な問題例を現実的な計算手間で解く効率的なアルゴリズムが開発されている。
- 線形計画問題の定式化 → 代表的なアルゴリズムである **単体法** → 数理最適化においてもっとも重要な概念である **双対問題と緩和問題**。

### 3章 非線形計画
- 非線形計画問題は適用範囲が非常に広い一方で、多様な非線形計画問題を効率的に解く汎用的なアルゴリズムの開発は難しい。
- 非線形計画問題の定式化 → 効率的に解ける非線形計画問題の特徴 → 制約なし最適化問題と制約つき最適化問題の代表的なアルゴリズム。

### 4章 整数計画と組合せ最適化
- 整数計画問題（線形計画問題において変数が整数値のみをとる問題）は、産業や学術の幅広い分野の現実問題を定式化できる汎用的な最適化問題の1つ。
- 整数計画問題の定式化 → 組合せ最適化問題の難しさを評価する **計算の複雑さの理論** の基本的な考え方 → いくつかの特殊な整数計画問題の効率的なアルゴリズム → 代表的なアルゴリズムである **分枝限定法と切除平面法** → 任意の問題例に対して近似性能の保証を持つ実行可能解を求める **近似解法** → 多くの問題例に対して質の高い実行可能解を求める **局所探索法およびメタヒューリスティクス**。

## 学習順序の例（図1.9）

- 2章「線形計画」と3章「非線形計画」の内容はほとんど独立しているので、必ずしもこの順に読み進める必要はない。
- 微積分と線形代数を学んで間もない大学生などであれば、3章「非線形計画」の方が数理最適化の入門には良いかもしれない。
- 4章「整数計画と組合せ最適化」は2章「線形計画」の内容を前提としているので、先に2章を読むことを勧める。
- 図1.9（本書の学習順序の例）：
  - **数理最適化を広く勉強したい人**：第1章 → 第2章 → 第3章 → 第4章、または第1章 → 第3章 → 第2章 → 第4章。
  - **連続最適化を勉強したい人**：第1章 → 第2章 → 第3章、または第1章 → 第3章 → 第2章（第4章は淡色表示で対象外）。
  - **離散最適化を勉強したい人**：第1章 → 第2章 → 第4章（第3章は淡色表示で対象外）。
