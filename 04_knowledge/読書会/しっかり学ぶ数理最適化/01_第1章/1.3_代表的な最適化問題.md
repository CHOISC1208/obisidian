# 1.3 代表的な最適化問題

← [[1.2_最適化問題]] | ↑ [[しっかり学ぶ数理最適化_MOC]] | → [[1.4_本書の構成]]

## 分類の観点

- 最適化問題はさまざまな観点にもとづき分類できるが、**変数・目的関数・制約条件の種類**により分類する場合が多い（図1.7）。
- 図1.7（代表的な最適化問題）：左側に「連続最適化問題」のグループとして非線形計画問題・2次計画問題・線形計画問題、右側に「離散最適化問題（組合せ最適化問題）」のグループとして整数計画問題・混合整数計画問題・ネットワーク最適化問題が、それぞれ小さなイラスト付きで並べられている。

## 連続最適化問題

- **連続最適化問題**（continuous optimization problem）：変数が実数値のような連続的な値をとる最適化問題。
  - **実数変数**（real variable）：実数値をとる変数。
- **線形計画問題**（linear programming problem; LP）注7：目的関数が線形関数で、すべての制約条件が線形の等式もしくは不等式で表された最適化問題。
  - 注7：ここでは programming は「計画を立てる」という意味。
- **非線形計画問題**（nonlinear programming problem; NLP）：非線形関数で表された目的関数や制約条件を含む最適化問題。
- **2次計画問題**（quadratic programming problem; QP）：目的関数が2次関数で、すべての制約条件が線形の等式もしくは不等式で表された非線形計画問題。

## 離散最適化問題（組合せ最適化問題）

- **離散最適化問題**（discrete optimization problem）／**組合せ最適化問題**（combinatorial optimization problem）：変数が整数値や $\{0, 1\}$ の2値のような離散的な値をとる最適化問題、または最適解を含む解の集合が順列やネットワークなど組合せ的な構造を持つ最適化問題。
  - **整数変数**（integer variable）：整数値のみをとる変数。
  - **2値変数**（binary variable）：$\{0, 1\}$ の2値のみをとる変数。
- **整数計画問題**（integer programming problem; IP）：すべての変数が整数値のみをとる線形計画問題。
- **混合整数計画問題**（mixed integer programming problem; MIP）注8：一部の変数が整数値のみをとる線形計画問題。
  - 注8：最近では **混合整数非線形計画問題**（mixed integer nonlinear programming problem; MINLP）と区別するために **混合整数線形計画問題**（mixed integer linear programming problem; MILP）と呼ぶことも多い。
- **2値整数計画問題**（binary integer programming problem; BIP）／**0-1整数計画問題**（0-1 integer programming problem）：すべての変数が2値のみをとる整数計画問題。
- **ネットワーク最適化問題**（network optimization problem）：ネットワークやグラフで表される最適化問題。
