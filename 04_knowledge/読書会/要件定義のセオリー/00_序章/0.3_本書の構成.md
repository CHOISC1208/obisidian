# 0.3 本書の構成

← [[0.2_本書が目指すもの]] | ↑ [[要件定義のセオリー_MOC]]

| 章 | 内容 |
|---|---|
| 序章 | 本書における要件定義の考え方 |
| 第1章 | 「情報システム」と「要件定義」に対する著者の価値観 |
| 第2章 | 要件定義の目的・作業内容・成果物・留意点 |
| 第3章 | 本来、要件定義の前に済ませておくべき作業 |
| 第4章 | 業務プロセス／画面UI／データといった設計対象ごとに「概要から詳細へ」要件定義を進める手順 |
| 第5章 | 非機能要件 |
| 第6章 | 必要となるアーキテクチャ |
| 第7章 | 要件定義内容の妥当性確認・合意形成 |

全編を通じたテーマ：要件定義で押さえるべきポイントを「セオリー」として示し、**最小の労力で最大の成果** を出す。

## 読み方メモ

- 実務で即使うなら **第3章 → 第4章 → 第7章** が中心。第4章は各節に「〜の手順」Column があり、手順ナレッジとして独立させやすい
- 第1〜2章は思想・前提。チーム内で要件定義の共通言語を作る際の説明材料に向く
