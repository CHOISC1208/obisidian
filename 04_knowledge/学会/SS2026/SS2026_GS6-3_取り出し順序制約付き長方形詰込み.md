# 再配置による取り出し順序制約付き長方形詰込みレイアウトの改善

> [!abstract] 一言で
> 自動倉庫で「他の品を動かさず指定順に上方向へ取り出せる」制約（取り出し順序制約）付きの長方形ストリップパッキング（2SPR）に対し、BL法を拡張した構築型解法 **ABS（Adaptive Bottom-Stable）法**を提案。
> 取り出し順の逆順に配置し、水平に動かない安定点（BS点）を5基準の加重和で選択、最後に上部の長方形だけ「高さ増加抑制」重視で再配置。BL法に対しベンチマークで充填率 71.8%→84.3%（+12.5pt）、256個ランダムで 86.9%→91.1%、いずれも1秒未満。

## 背景・動機
- 倉庫自動化市場の急成長。自動倉庫では保管品を他を動かさず所定の順序で取り出す運用が多いが、既存のパッキング研究は取り出し順序制約を考慮していない
- 2SPは強NP困難。実用上は高速な構築型解法が有用

## 問題設定：2SPR
- 幅Wの容器、長方形 R={1..n}（幅 w_i、高さ h_i、90°回転可）、取り出し順序 σ_i（昇順に取り出す）
- **取り出し順序制約**：iとjが水平に重なりjがiの上にあるなら σ_j < σ_i（後で取り出すものが上にあってはいけない）
- 目的：容器高さ H の最小化（＝充填率最大化）
- 定式化：0 ≤ x_i ≤ W−w_i、0 ≤ y_i ≤ H−h_i、任意のi≠jで「x_i+w_i ≤ x_j」or「x_j+w_j ≤ x_i」or「y_j+h_j ≤ y_i かつ σ_i < σ_j」のいずれか

## 提案手法：ABS法
- **逆順配置**：取り出し順の逆に1つずつ置く → 新しい長方形は既配置より先に取り出されるので制約を自動的に満たす
- **BS点（Bottom-Stable点）**：垂直位置を保ったまま水平に動かせない配置可能位置（既配置または壁で左右いずれかが決まる安定位置）。全BS点を列挙し評価関数で1つ選ぶ
- **5つの評価基準**（小さいほど良い）
  1. f_y = y_p：低い位置優先
  2. f_update = max{y_p + h_i − H_cur, 0}：レイアウト高さの増加量
  3. f_v-gap = |y_p + h_i − max(隣接長方形の上辺y)|：上面の平坦さ
  4. f_h-gap = w_i − c_i(p)：下辺の非接触長（下に隙間を作らない）
  5. f_neighbor = 2(w_i+h_i) − (c_i + l_i + r_i)：周長のうち非接触部分（密着度）
- F(p) = α f_y + β f_update + γ f_v-gap + δ f_h-gap + ε f_neighbor、argmin を選択。BL法は [1,0,0,0,0] の特殊ケース
- **再配置**：全部置いた後、他を動かさず1回の上方向移動で取り出せる（＝最上部にある）長方形を取り除き、f_update の重みを極端に大きくした重み [3,9999,1,1,1] で置き直す。再配置前後で充填率が高い方を採用（終盤は隙間の適合性より高さの増加抑制が重要という観察）

## 何が難しいか
- 取り出し順序制約により配置自由度が大きく制限され、通常のBL法の「最も低く左へ」だけでは隙間が残る
- 終盤（残り数個）の配置で新しい段ができると最終高さが跳ねる → 序盤と終盤で最適な配置基準が違う

## 実験設定
- 重み α〜ε ∈ {0,1,2,3} の 4⁵=1024 通りを、別に生成した256個ランダム100問でグリッドサーチ → [3,2,1,1,1] を採用
- ベンチマーク：Hopper & Turton の21問（16〜197個、σ_i = i）。ランダム：256個、寸法U[1,100]、W=500、100問
- Python 3.12、MacBook Air M1 8GB

## 結果・評価
| 問題例 | BL 充填率 | ABS 充填率 | 時間 |
|---|---|---|---|
| ベンチマーク21問 | 71.765% | **84.280%** | 0.05s / 0.05s |
| ランダム256個×100 | 86.853% | **91.135%** | 0.42s / 0.43s |

- 21問全てでABS > BL。分布全体が上方シフト
- ベンチマークでの改善（+12.5pt）がランダム（+4.3pt）より大きい → 寸法構成が改善率に影響（ランダムはBLでも既に高い）。要因分析は今後
- 計算時間は同程度、256個でも1秒未満

## 実務への示唆
- **配置の後に取り出す順序が決まっている**（先入れ後出しのバッファ、トラック積載、パレット積み付け、仮置き場）保管レイアウト問題への直接的な参照。逆順配置で制約を自動充足する発想はシンプルで実装しやすい
- 「複数の幾何学的評価基準を加重和にし、重みをオフラインでグリッドサーチ」「終盤は別の重みで再配置」という構築型ヒューリスティクスの改善パターン。数秒で解が必要なオンライン運用向き
- BL法との比較で12ptという改善幅は、現場の充填率向上の目安として使える数字

## 先行研究との位置づけ
- 切断・詰込み問題の類型（Dyckhoff 1990）、BL法（Baker, Coffman & Rivest 1980）、ベンチマーク（Hopper & Turton 2001）。取り出し順序制約付きは既存研究で扱われていないと主張

## 気になる点・[要確認]
- 比較対象がBL法のみ。メタヒューリスティクス（例：BLベースのGA/SA）や下界との比較はない
- ベンチマークのσ_i = i は人工的。実運用の取り出し順序の分布に依存する可能性
- 回転（90°）を評価関数の中でどう扱ったか（BS点候補に回転版も含めたか）が本文では明示されず
- 重みは256個ランダム問題でチューニング → ベンチマークへの転移性は結果が示すが、他の寸法分布では再チューニングが必要かも
