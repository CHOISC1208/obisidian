# 混合整数線形最適化と機械学習に基づいた配送計画問題の近似解法

> [!abstract] 一言で
> CVRPを「MILOで顧客を車両に分割 → 各車両でTSPを厳密に解く」クラスタ先ルート後法で解く。分割の良さを評価する目的関数に、**TSP最適値を予測するCNNを線形不等式系として埋め込む**のが新規点。
> 車両数が多いとFisher–Jaikumar法より良い解。ただし同一時間制限ではMTZ制約の直接MILO定式化（厳密解法）の方が依然優位。

## 問題設定
- 対象：ℓ×ℓ（ℓ=64）格子上のCVRP。顧客 n≤100、車両 m≤5、各顧客に需要 w_i、車両容量 Q
- 出力：顧客集合 C の分割 C_1..C_m と各車両の巡回路。総巡回路長最小化
- 前提となる観察：MILOソルバは巡回路を扱う問題（VRP/TSP）は苦手だが、分割・割当問題は得意。ならば分割だけMILOに任せる

## 定式化の要点
- 変数：a_ik（顧客i→車両k割当 0-1）、b_k（車両kの需要総和）、v_kpq（車両kが格子点(p,q)を訪問 0-1）、φ_k（車両kのTSP最適値予測、実数）
- 制約：デポは全車両に割当／各顧客はちょうど1台／b_1≤b_2≤…≤b_m≤Q（容量＋車両対称性除去）／v_kpq と a_ik の連動／**φ_k = N(v_k11,…,v_kℓℓ)** ← 学習済みCNN N を線形不等式系で記述
- 目的：Σ_k φ_k 最小化
- CNN入力は 0/1 の ℓ×ℓ 画像（顧客配置）＋数値特徴（顧客数、バウンディングボックス高さ・幅）。ReLU・MaxPoolをBig-Mで線形化

## 何が難しいか
1. **Big-Mの爆発**：CNNが深くなるほど各層の入力範囲が積み重なりBig-Mが巨大化（(1,4,8)で1.26×10^4 → (4,8,128)で6.75×10^9）。LP緩和が弱くなり、B&Bの下界改善が進まない
2. 予測精度とMILOの解きやすさのトレードオフ：精度の高い深いCNNほどMILOに載せられない
3. MILOの最適解 ≠ CVRPの最適解（予測誤差の分だけ最終解が劣化する。A-n37-k5で顕在化）
4. 変数・制約数は車両1台あたり約5.7万変数・9.4万制約とほぼ全て予測関数由来。車両数に比例して増える

## 工夫・アプローチ
- **学習データの大量自動生成**：格子上ランダムTSP 10^6問をConcordeで厳密に解いて最適値ラベルを得る（顧客数5〜30）
- 精度は絶対値ではなく**分割の順位保存**が本質と割り切り、順位相関係数で評価（(1,4,8)で0.614、(4,8,128)で0.935）。m台分の予測を足すと誤差が打ち消し合いMAPEが下がる
- 浅い2アーキテクチャ (1,4,8),(2,1,8) のみMILO化。数値特徴（顧客数等）の追加は浅いネットの精度向上に効く
- warm start に貪欲法（需要降順に空き容量最大の車両へ）の解を使用
- 制約を「MILOで書ける限り何でも追加できる」拡張性、m個のTSPを並列に解ける点を利点として主張

## 実験設定
- Amazon EC2 g6.8xlarge（NVIDIA L4）、Gurobi 13.0.2、TensorFlow 2.21、600秒上限
- CVRPLib A/B/E/F/P、車両数≤5、64×64格子へ写像して同一セルに2点以上落ちない21インスタンス
- 比較：貪欲法、Fisher–Jaikumar法（k-meansクラスタ→一般化割当、乱数種5回）、MTZ制約の直接MILO（Gurobi）

## 結果・評価
- 提案法(1,4,8)は全問で初期解（貪欲）を改善。(2,1,8)は改善できない問題あり（P-n76-k4など）
- 車両数 m が小さい（2〜3）とFJ法優位、m=4〜5で提案法が優位。FJは乱数依存で解のばらつきが大きい
- **厳密解法（MTZ直接）は3問を除き提案法より良い暫定解**。ただし n≤70 では提案法のギャップの方が小さい傾向
- 今後：損失関数に正則化を加えてBig-Mを小さく学習する、効率的なアーキテクチャ探索

## 実務への示唆
- 「学習済みモデルの出力を最適化モデルの目的関数/制約に埋め込む」（Optimization with Trained Predictors）の国内実装例。Big-M問題の具体的な数値感が得られる
- 現時点では小規模VRPなら直接MILOで解いた方が良い、という正直な結論。学習ベース手法を検討するときの比較基準として引用しやすい
- 「近似関数は絶対精度より順位保存」という評価観点は、代理モデルを最適化に使う場面全般に転用できる
- 巡回セールスマンの最適値を「画像認識」で推定する発想（橋本ら SS2025 の続編）

## 先行研究との位置づけ
- Varolら (Transportation Science 2024)：NNでTSP最適値予測、MAPE 0.67%。ただし顧客数固定・MILO埋め込み不可
- 橋本ら (SS2025)：CNNによる平面TSP最適値推定、MAPE 1%程度。本研究はそれをMILOに組み込む方向へ発展

## 気になる点・[要確認]
- 格子64×64・車両≤5・顧客≤100 という強い制限。実務規模への拡張性は未検証
- CNN線形化の詳細（Big-Mの計算法含む）は「紙面の都合で省略」
- 深いCNNを使いつつBig-Mを抑える方法（OBBTなどのバウンドタイトニング）への言及なし
