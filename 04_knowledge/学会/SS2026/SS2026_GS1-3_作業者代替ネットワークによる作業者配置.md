# 作業者の欠員を考慮した作業者代替ネットワークによる作業者配置手法の研究

> [!abstract] 一言で
> ジョブショップの各機械に主担当作業者を配置するとき、「作業量の多い機械に高技能者を置く」（スキルインデックス最大化）だけでなく、**欠員時に誰が誰を代替できるかを有向重み付きネットワークで表し、その強度を最大化**する配置を提案。
> 通常時・平均的な2名欠員では両者ほぼ同等。50×50規模で高技能者上位2名が同時欠員した場合、メイクスパン 9166→7200（**約21.4%減**）。

## 背景・動機
- 人依存度の高い生産システムでは作業者ごとの技能差が生産性を左右。著者らはセル生産で技能習熟・教育を考慮した配置を研究してきた[1]
- 計画時に予測できない突発欠員は現実に起きる。特に高技能者の欠員は影響が大きい
- 先行研究（Bocewiczら[5]、Szwarcら[6]）はコンピテンシーと代替可能性でロバスト性向上を扱う。著者らの前研究[8]はセル生産のタクトタイムで評価しており、**欠員で生じるスケジュール変化を直接評価していなかった**のが残課題

## 問題設定
- ジョブショップ：各ジョブは工程列、工程ごとに機械と順序が固定。各機械に主担当作業者1名
- 機械を**機械グループ**に分割（実験では2グループ）。作業者は主担当機械の所属グループに属する
- 欠員時：同一グループ内の他作業者が欠員者の担当機械の作業を**自分の担当と兼務**して代替（同時実施は不可）。グループをまたぐ代替は認めない
- **スキルインデックス** S_im = ET_im / ST_m（標準作業時間÷実作業時間の比。>1で速い）。実処理時間 P_ijm = P_jm / S_im
- 代替作業者の処理時間も、その人の当該機械に対するS_kmで決まる → 欠員時の生産性は「代替者がいるか」だけでなく「代替者の技能」に依存

## 提案手法
### 比較基準：スキルインデックス最大化
- F_S = Σ_i Σ_m W_m S_im x_im を最大化（W_m：機械mの作業量）。作業量の多い機械に高技能者を優先配置

### 作業者代替ネットワーク
- ノード＝作業者。作業者iの主担当機械 m(i) に対し、同グループの作業者kが S_{k,m(i)} ≥ S_th ならリンク i→k（重みは S_{k,m(i)}）
- ネットワークは**配置に依存**：主担当機械が変わると所属グループも代替関係も変わる

### ネットワーク強度最大化（辞書式優先順位）
1. 各作業者の代替候補数の**最小値**を最大化（誰が欠けても代替者がいる配置を優先。ボトルネック排除）
2. 代替リンク総数を最大化
3. リンク重み（代替者のスキルインデックス）総和を最大化
4. 同値なら作業量重み付きスキルインデックスを最大化

### 3手法目：最悪ケース最小化
- 欠員時の最悪メイクスパンを直接評価する配置探索（900秒）。本文の結果表には未掲載 [要確認]

## 実験設定
| 項目 | 8×8 | 20×20 | 50×50 |
|---|---|---|---|
| ジョブ・機械・作業者数 | 8 | 20 | 50 |
| 機械グループ数（機械数/G） | 2 (4) | 2 (10) | 2 (25) |
| 2名欠員パターン数 | 28 | 190 | 1225 |

- スキルインデックス値 {0.8, 1.0, 1.2}、代替閾値 0.8、標準処理時間 55〜95、配置決定30秒、1シナリオ求解60秒、CP-SAT 8ワーカー
- 配置後、ディスパッチングルールでスケジューリングしメイクスパン算出。通常時／2名欠員全組合せ平均／高技能者上位2名欠員 の3指標

## 結果・評価
| 規模 | 手法 | 欠員なし | 2名欠員平均 | 高技能者2名欠員 |
|---|---|---|---|---|
| 8×8 | スキル | 764 | 980.5 | 1189 |
| | ネットワーク | 764 | 971.1 | 1204 |
| 20×20 | スキル | 2100 | 2218.1 | 2330 |
| | ネットワーク | 2074 | 2217.6 | 2336 |
| 50×50 | スキル | 5407 | 5668.7 | **9166** |
| | ネットワーク | 5419 | 5675.0 | **7200** |

- 通常時・平均欠員ではほぼ差なし → ネットワーク重視にしても平時の生産性は落ちない
- 50×50の高技能者欠員で1966（21.4%）差。スキル最大化は高技能者を作業量最大の機械に集めるため、その人が抜けると代替者の技能次第で大崩れする
- 小規模（8×8）では高技能者欠員時にネットワーク法がむしろ僅かに悪い
- 今後：規模・技能分布・欠員人数の変化、ネットワーク構築条件と閾値 S_th の感度

## 実務への示唆
- 「最適配置」と「欠員に強い配置」は平時のコストがほぼ同じで**下振れだけ大きく違う**、という定量例。ロバスト配置を提案するときの説明材料
- **辞書式（優先順位付き）多目的**で「最小代替候補数の最大化」を第1目的に置く発想は、ボトルネック解消型の配置・要員計画に使いやすい
- 代替ネットワークは配置と相互依存する（配置を変えるとネットワークが変わる）ので、単純な事前計算ではなく最適化の中で評価する必要がある、という設計上の注意
- 機械グループ（代替が許される範囲）の切り方が結果を左右する。実務では組織単位・レイアウト・資格で決まる

## 先行研究との位置づけ
- Yueら (IJPR 2008)：作業者と機械の二重資源制約ジョブショップにおける多能工化・技能重複の効果
- Liら (COR 2024)：作業者シフト付きフレキシブルジョブショップの2段階最適化
- Bocewiczら (2021)、Szwarcら (2024)：コンピテンシー駆動のロバスト人員配置・ジョブローテーション
- Ouelhadj & Petrovic (2009)：製造の動的スケジューリング概観

## 気になる点・[要確認]

- 配置決定の最適化手法（CP-SATで辞書式目的をどう解いたか、それとも探索か）の記述が薄い
