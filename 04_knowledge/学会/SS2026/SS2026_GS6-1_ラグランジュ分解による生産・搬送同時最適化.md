# 空搬送を考慮したラグランジュ分解・調整法による生産・搬送計画同時最適化手法の性能評価

> [!abstract] 一言で
> AGV搬送付きジョブショップ（総納期遅れ最小化）を、機械能力制約をラグランジュ緩和してジョブ別部分問題（DP）に分解し、リストスケジューリング＋搬送経路決定で実行可能化する既提案手法の性能評価。
> 課題は下界算出時に**空搬送**（AGVが次の荷を取りに行く移動）が無視され双対ギャップが大きいこと。対策として①見なし空搬送時間（固定加算）②前反復の実空搬送を次反復のペナルティに反映、の2案を比較。②のγ=0.010が最良UB。

## 背景・動機
- AGVは「必要な時に必要な場所へ」が要点で、単なる搬送自動化では不十分。生産状況を考慮したAGV作業割当・衝突回避を含む生産・搬送同時計画が必要
- 生産計画・搬送計画・搬送経路計画を全部同時に決めると変数が爆発 → 分解して段階的に決める（既提案[4]）

## 問題設定
- レイアウト：搬入口・搬出口・加工機械がノード上、AGVはエッジを移動（ノード間距離は全て同一）。エッジ双方向可だが**同時に複数AGVが同一エッジ・ノードに侵入不可**
- ジョブは搬入→指定順の加工機械→搬出。工程は搬送（奇数番）と加工（偶数番）が交互。処理時間・納期あり
- 機械は同時1ジョブ、バッファ無制限。AGVは同時1ジョブ
- 加工機械 1..M と AGV M+1..M+V を「機械」として統一的に扱う
- 目的：総納期遅れ Σ_j L_j、L_j = max{0, 完了 − D_j}

## 定式化の要点
- 変数 x_{j,k,m,t}（ジョブj工程kが期tに機械mで処理中なら1）、開始 bt、完了 ct
- 原問題制約：機械能力 Σ_j Σ_k x ≤ 1 ∀m,t（緩和対象）、先行 bt_{j,k+1} ≥ ct_{j,k}+1
- **緩和問題**：能力制約に乗数 λ_{m,t} ≥ 0 → 目的 ΣL_j + Σ_m Σ_t λ_{m,t}(Σ x − 1)。ジョブごとに分解可能
- **部分問題**：min L_j + Σ_k Σ_m Σ_t λ x を**DP**で解く。F_{j,k,m,t} = min_{t'} {F_{j,k−1,m',t'} + Σλ} の再帰、工程1〜K+Hを順に
- **乗数更新**：劣勾配法。λ ← max{0, λ + α·D}、D = Σx − 1、ステップ α = π(UB−LB)/‖D‖²、πは上界が一定回数更新されないと半減

## アルゴリズム
1. 原問題作成 → 2. 能力制約を緩和 → 3. 乗数初期化・ジョブ別に分解 → 4. DPで部分問題を解き下界 → 5. 実行可能化（下記）で上界 → 6. 終了条件（反復3000／双対ギャップ≤10⁻⁶）でなければ乗数更新し4へ
- **Step 5 実行可能化**（Luhらのリストスケジューリング参考）：緩和解の全工程を開始時刻順にリスト化 → 先頭が搬送なら**実空搬送時間を考慮して**AGVに割当、加工なら機械に割当 → 全部割り当てたら暫定解
- **搬送経路決定**：各搬送を最短経路で初期化 → 期tのAGV位置で干渉判定 → 干渉あれば等価な代替経路／待機・迂回で回避 → 後工程に影響が出れば開始時刻を遅らせる → 全期間で干渉なしまで反復

## 何が難しいか
- 部分問題（下界）は空搬送を無視するため、実行可能化時に空搬送分の遅れが積み上がり **UB−LBの乖離が大きい**
- 空搬送の有無・所要時間は下界算出時には不確定（どのAGVがどこにいるか決まっていない）
- 空搬送を考慮すると下界の最適性保証が失われる（緩和問題の近似解になる）→ 精度と理論保証のトレードオフ

## 工夫・アプローチ
- **提案1 見なし空搬送時間**：全搬送工程に固定 ft を加算 p_t = e_t + ft。余裕のある部分問題解を作る
- **提案2 空搬送ペナルティ**：反復nの実行可能解で工程(j,k)に生じた空搬送時間 eft を記録。次反復で工程k−1とkの間に eft 以上の遊休がなければペナルティ μ_{j,k,t} = max{0, γ(eft − 遊休)} を部分問題の目的に加える → 前回空搬送が起きた時間帯に処理を置きにくくする

## 実験設定
- 計画期間400、ジョブ10、機械4、AGV 3 or 5。処理時間U(5,10)、納期U(1, 2×総処理時間)。α初期0.005、π=2.0、各30セット

## 結果・評価
| (J,M,V)=(10,4,3) | UB | LB | 時間[s] |
|---|---|---|---|
| 比較（空搬送考慮なし） | 385.8 | 243.1 | 7.45 |
| 提案1 ft=1 | 380.0 | 259.2 | 7.58 |
| 提案1 ft=2 | 381.8 | 278.1 | 7.44 |
| 提案1 ft=4 | **389.0（改悪）** | 325.8 | 7.48 |
| 提案2 γ=0.001 | 383.3 | 243.1 | 10.59 |
| **提案2 γ=0.010** | **376.1** | 243.9 | 11.12 |
| 提案2 γ=0.050 | 379.0 | 247.8 | 11.22 |

- 提案1：ftを増やすとLBは単調に上がる（余裕を持った下界）が、UBはft=1,2で改善、ft=4で改悪 → **空搬送を過大に見積もると解が悪化**
- 提案2：γ=0.010が両規模で最良UB。LBは比較手法と同程度 → 実際の空搬送を反映した「良い構造の下界」が効いた。ただし計算時間は約1.5倍。γは問題規模で調整が必要
- 今後：レイアウト変更・他条件での検証

## 実務への示唆
- **分解法で無視した相互作用（ここでは空搬送）が上界と下界の乖離を生む**とき、(a)固定マージンを乗せる、(b)前回の実行可能解から学んだ違反量をペナルティで戻す、の2アプローチとその挙動（過大マージンは逆効果、フィードバック型が安定）は他の分解問題にも共通
- ラグランジュ分解・調整法の標準構成（緩和→ジョブ別DP→劣勾配→リストスケジューリングで実行可能化）の丁寧な手順書として読める
- 生産と搬送を同時に考えたいが単一MILPが無理、という時の現実的な選択肢。なお乗数を交換する分解は「価格情報が漏れる」（GS1-2の指摘）ので企業間には不向き

## 気になる点・[要確認]
- 10ジョブ・4機械・計画期間400と小規模。双対ギャップは依然 (385.8−243.1)/243.1 ≈ 59% と大きく、下界の質は課題のまま
- 表の(10,4,5)列は一部欠損（ft=3,4の値が読めない）
- 搬送経路決定の「等価な経路」の定義、干渉回避の優先順位が簡潔
- 空搬送ペナルティのγが問題依存で自動調整策なし
