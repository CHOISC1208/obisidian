# 弾性光ネットワークにおける資源効率的な動的セグメント経路保護

> [!abstract] 一言で
> 弾性光ネットワーク（EON）で単一リンク障害に備える保護経路は、主経路とリンク非共有にすると迂回で長くなりスペクトルを食う。主経路を複数セグメントに分け、各セグメントに短い迂回保護を付ける**セグメント保護**を動的RSAに適用。
> 分割法3種（S字＝共通内点で分割、L字＝共通リンク軸、**AUX＝補助グラフ上の最短経路で分割点を系統選択**）を提案。分割は「非分割の割当失敗後の最終手段」として使うのが有効で、AUXは規則的メッシュでブロッキング率2〜3割削減、不規則網でも悪化しない。

## 背景・動機
- IPトラヒック急増、EONは周波数スロット（FS, 12.5GHz）単位でスペクトルを柔軟割当。RSA問題（経路＋連続・隣接するFS割当）はNP困難、断片化でブロッキング
- 光信号は距離で劣化 → 再生器（電気変換して整形）。透過型（再生器なし・安価・到達距離制限）と半透過型（必要ノードのみ再生器）
- 単一ファイバ障害が大量の接続に波及 → 主経路とリンク非共有の保護経路を事前確保。**SBPP**（主経路同士がリンク非共有なら保護資源を共有可）で資源削減
- 保護経路は迂回で長い → FS増、変調効率低下、共有機会減。パス保護（全体1本）とリンク保護（リンクごと）の中間としてセグメント保護。EONでの検討は少なく、SBPP下の半透過型はさらに少ない

## 問題設定
- 有向グラフ G=(V,E)、リンク長 l_e、FSインデックス集合 F。要求 r=(s_r, d_r, 情報量 t_r, 保持時間 τ_r)
- **距離適応変調**：セグメント長 L_S で変調方式が決まり必要FS数 n^r_S = ⌈(t_r/t_mS · W_OC + 2W_GB)/W_FS⌉（W_OC=37.5, W_GB=6.25, W_FS=12.5 GHz）。t_mS = 200/150/100/50 Gbps（L_S ≤600 / 1200 / 3500 / 6300km）、D_max=6300km
- 動的シナリオ：要求は到着まで不明、到着後即座に割当、資源不足ならブロック。評価は帯域幅呼損率 BBR
- 候補経路ペア（主・保護）を必要FS数の少ない順に k=5 本事前生成
- 半透過型：再生器は休止／待機（保護用、共有可）／稼働（主経路用、共有不可）の3状態。分割点の再生器はスペクトル連続性を切るので同一FSインデックス制約が消える

## 提案手法
1. **S字分割（共通ノード型）**：主経路 Pw と保護経路 Pb が内点を共有するとき、その1つを分割点にして Pb を2本に。3経路がSの字を成す。分割点より先は主経路のスロットを再利用
2. **L字分割（共通リンク型）**：主経路候補間で共有するリンクセグメントを軸に、前半・後半を別々の保護経路で守る（分割点なし）。事前に候補をホップ数の少ないものに絞る
   - 透過型では主経路と2本の保護経路が**同一FSインデックス**を使う必要 → 3経路の変調方式一致を条件とする版／しない版を用意
   - 半透過型では Pb のホップ数を Pw の1.3倍以内に制限
3. **AUX分割（補助グラフ型）**：Cavalcanteら[7]の再生器割当の枠組みを利用。主経路の内点（再生器割当可能）を頂点とし、区間 v_s–v_d と その迂回路 B_sd が共に D_max 以内なら有向辺を張る。辺コスト C = δ（分割回数）+ w·slots（迂回のFS数）+ w²·(r_v/R_v)（再生器逼迫度）、w=10⁻³。k_aux=3 本の最短経路を求め、内点集合＝分割点、各辺＝迂回保護経路。上位から割当可能な構成を採用。ホップ数の少ない主経路上位3本に順に適用
- **分割タイミング**：即時／再生器無の失敗後（A後）／再生器有の失敗後（B後）
- FS割当：主経路は低周波側から前詰め、保護経路は高周波側から後詰め（First-Fit Last-Fit）。透過型の分割構成は3経路とも後詰め

## 何が難しいか
- 透過型では分割してもFSインデックスが3経路で揃わないと割当できず、距離適応変調とあわせて条件が厳しい（L字は一度も採用されず）
- 分割しすぎ（過分割）はFSを消費し、非分割で足りる要求まで長い保護経路に追いやる → タイミング設計が本質
- 半透過型は再生器（稼働・待機）がボトルネックになりうる。S字は分割点で主経路を再生するので稼働再生器が多く、L字は2分割点で待機再生器が多い

## 実験設定
- 透過型：US26。半透過型：5×5メッシュ（再生器80）、Waxmanランダム網（二重連結、再生器100、頑健性評価）
- 要求：情報量 U{50,100,150,200}Gbps、保持時間 U[10,300]、ポアソン到着 λ=0.7〜1.2、1試行1000要求。FS数はBBR≈5%になるよう調整（US26 280 / mesh 400 / Waxman 300）
- 対応差の95%信頼区間で評価（Waxmanは平均のみ）

## 結果・評価
- **透過型（US26）**：S字B後は全負荷で非分割を有意に下回る（保護経路1本あたりの距離短縮で、D_maxを超えていた主経路も割当可能に）。S字即時は低負荷で改善するが高負荷で悪化：分割回数がB後の平均37倍と過剰。L字は効果なし（B後では採用0）
- **半透過型 mesh**：AUXが両タイミングとも全負荷で非分割を大きく下回り**BBR 2〜3割削減**。S字が次、L字は限定的。計算時間は全手法7秒程度、AUX-A後でも+1秒程度
- **半透過型 Waxman**：多くの手法は−10〜0%にとどまる（共通内点を持つ分割可能構成が生まれにくい）。**AUX-B後は全負荷で安定して非分割を下回り、性能を落とす負荷点がない**。A後は不規則網で過分割傾向
- 平均分割回数（1000要求あたり、mesh）：S 151.0(A後)/4.7(B後)、L 98.4/1.1、AUX 261.8/20.5
- 今後：大規模網、再生器容量・設置制約の現実化、分割点を軸とした分割構成の組合せ最適化（分割点で主・保護の役割を入れ替えても等価）

## 実務への示唆
- **冗長化（バックアップ経路・予備リソース）のコストを、対象を分割して「短い予備」を複数持つことで下げる**発想は、物流の代替ルート、設備のバックアップ配置、電力・水道網の保護にも共通
- **フォールバックとしての適用**（通常の割当が失敗したときだけ高度な手法を試す）が過剰適用を防ぎ頑健、という設計指針。B後 vs 即時の比較はその定量例
- 選択問題を補助グラフ上の最短経路に帰着し、コストに「主目的＋タイブレークを微小重みで」を載せる（AUX）という定式化テクニックは汎用性が高い
- 規則的トポロジと不規則トポロジの両方で評価し、悪化しないことを頑健性として示す評価設計

## 気になる点・[要確認]
- 障害発生時の切替動作や復旧時間は評価対象外（資源効率のみ）
- 分割数は最大でも数個。多重障害は対象外
- Waxmanの結果は平均のみで信頼区間なし
