# Prevision（勤怠・外部製品）

親: [[00 MOC|ケーテック株式会社 MOC]]

| 項目 | 内容 |
|---|---|
| 製品名 | Prevision |
| ベンダー | 株式会社インプローブ |
| 用途 | 勤怠管理（有休・半休の管理、給与連絡） |
| **連携システム** | **なし**（2026-08-17 確定） |

## 現行の運用（変えない）

```
Prevision で有休・半休を選択
  → Excel に書き出し
  → 社労士へメール送付
```

> [!important] この手動フローは変更しない
> 2026-08-17 のヒアリングで「連携システムはなし」と確定した時点で、
> **[[申請ポータル - APP No.07 年休申請|年休申請]]から Prevision への自動反映はスコープ外**と決めた。
>
> No.7 の元々の目的には「（なおよい）承認結果が勤怠データに自動反映されること」が挙がっていたが、
> API も CSV 取込も無いため実現手段が存在しない。
