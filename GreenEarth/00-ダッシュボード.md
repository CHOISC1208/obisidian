## この Vault の運用ルール

**reqnavi がタスク管理の正。** マイルストーン・カードのステータスはここに転記しない。同期されないため必ず古くなる。

この Vault が持つのは**動かないもの**。

| 置くもの | 置かないもの |
|---|---|
| 議事録（原文） | タスクの進捗・期限 |
| 判断の理由・経緯 | カンバンのステータス |
| 解決すべき課題の構造 | 日々の作業ログ |
| 調査結果・データ品質のメモ | |
| 未確定事項 | |

**課題（ISS-xx）が案件とプラットフォームをつなぐ接続点。** 案件ノートの「解決すべき課題」表にある「実装先」列が、コード側のノートへのリンクになる。

新しい案件を作るときは [[案件テンプレート]] を使う。
