# 命名規則

親: [[料理大砲 - 00 概要|概要]]

後から直すのが大変なので最初に決める。全部小文字・半角英数・アンダースコア区切り。

| 種別 | 接頭辞 | 例 |
|---|---|---|
| キャラ | `chr_` | `chr_hero_idle_01.png` |
| 背景 | `bg_` | `bg_forest_01.png` |
| UI | `ui_` | `ui_button_start.png` |
| 効果音 | `se_` | `se_jump.wav` |
| BGM | `bgm_` | `bgm_title.ogg` |
| スクリプト | PascalCase | `PlayerController.cs` |

## Unityのフォルダ構成（案）

```
Assets/
├─ Art/       Sprites, UI, Animations
├─ Audio/     BGM, SE
├─ Prefabs/
├─ Scenes/
└─ Scripts/
```
