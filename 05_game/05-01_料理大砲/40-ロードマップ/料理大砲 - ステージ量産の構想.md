# ステージ量産の構想

親: [[料理大砲 - ロードマップ]]

> 〔未確定〕考え中のメモ。2026-11-28 に出た案を、そのまま残す。決めたら[[料理大砲 - 決定ログ]]に移す。

## きっかけ

P3まで作ったら、「適当にぶつけても大体解ける」と分かった。ステージを増やす前に、**解けるか・どのくらい難しいか**を測る仕組みが要る。

## 案1：自動プレイで難易度を測る

Unity のバッチ実行で、全ステージを読み込み、角度×強さの全組み合わせを撃って確かめる。

| 数字 | 意味 |
|---|---|
| 解ける率 | 1球で解ける組み合わせ ÷ 全組み合わせ。小さいほど難しい |
| 解のまとまりの数 | 解ける組み合わせは隣り合った角度でまとまる。1まとまり＝1本の撃ち方。1本だけなら難しい。2本以上なら別の解き方がある |
| 解の幅 | 1本の中で、当たる角度が何段階分あるか。細いほど狙いがシビア |
| 1球で解けるか | あれば星3つの裏ワザがある |

- 解が0本：難しすぎる／壊れている。作り直し
- 解が多すぎる：簡単すぎる（今回の問題）
- 目安：解は1〜2本、幅は2〜3段階、1球で解ける裏ワザが1つだけ隠れている
- シーソーなど、1球目と2球目の当て方で変わるステージは、球数ぶん組み合わせが増える。1球目だけ測るか全部測るかは、動かしてから決める

## 案2：ステージのパラメータを増やす（検討中）

| 項目 | 案 | 状態 |
|---|---|---|
| 大砲の置き場 | JSON に `cannon: {x, y}` を足す。部品を増やさずに解き方を変えられる | やる方向 |
| 角度の刻み | 標準を5段階（15/30/45/60/75°）にして、ステージごとに変えられるようにする。やさしい面は粗く、むずかしい面は細かく | 賛成寄り |
| 強さをゲージにする | 押す長さ・タイミングで決める操作 | 見送り寄り |

ゲージを見送る理由：決定ログの「強さは3段階（細かい指操作ができない子供でも迷わないように）」に反する。連続値になり、解の数を数えにくくなる。必要なら、強さの値をステージごとに変えられるようにする。

## 案3：難易度表と手順書

- 難易度（やさしい／ふつう／むずかしい）ごとに、使える部品と置き方のルールを決める
- Claude がJSONを作るときの決まり（塔の安定のさせ方、部品の置ける場所）を書く
- ステージの並びは難易度順のリストで管理。3つ1セットで、最後に必ず終わる

## 方針メモ

- 1000個を目指すより、まず10〜30個をきちんと作る
- 物理ゲームは、自動で積むと勝手に崩れたり偶然解けたりしやすい。だから自動プレイで弾く
- 組み合わせは 3強さ×15角度 で約45通り。全部撃っても一瞬で済む
