# 試作タスク（M1〜M3）

親: [[料理大砲 - 00 概要|概要]] ／ マイルストーンは [[料理大砲 - ロードマップ]]

**方針：** 灰色の箱（グレーボックス）で、先に「撃って崩れる気持ちよさ」を確かめる。素材（Meshy）は、M2で面白さを確認してから作る。

**分業：** 実装とデータ追加は Claude、**遊んで判定するのは人間**。連鎖の挙動は人間のプレイテストが必須。各段階の最後に「遊ぶ」を置いてある。

## P0 準備

- [ ] Unity のバージョンを決める（過去の `carchase_game` は 6000.6.10f1 を使用。ノートは Git の履歴 `dc22fdd` に残っている。環境構築とiPadへの入れ方を再利用）
- [ ] 2Dプロジェクトを作成（URP の2Dテンプレート）
- [ ] 別リポジトリを作成。`.gitignore` に素材フォルダを `.meta` ごと入れる。素材のバックアップ先を決める（[[Unity×Git初期設定（調査）]]）
- [ ] iPad 横画面に設定。実機で空のシーンが動く
- [ ] フォルダ構成と命名規則を [[料理大砲 - 命名規則]] に合わせる

**完了条件：** iPad で空のシーンが起動する。

## P1 撃てる（M1：触れる）

1. [ ] **大砲**：左側のドラッグで角度を決める（スナップ。刻みは試作で調整）
2. [ ] **強さボタン**：右側に大きな3つ（弱・中・強）。選択状態が分かる
3. [ ] **撃つボタン**：押すと、選んだ角度と強さで弾が飛ぶ
4. [ ] **弾（食材）**：Rigidbody2D。スイカの灰色の球で、まず飛ぶ
5. [ ] **ガイド**：1バウンドまでの予測軌道線と、着地点の目印
6. [ ] 球数の表示（3球）と、残り球数が減る

**完了条件：** iPad で、両手で狙って撃てて、ガイドの着地点と実際の着地がほぼ合う。

**遊ぶ：** 子供の指で狙えるか（スナップの刻み、ボタンの大きさ）を確かめる。

## P2 崩せる（M2：ループが回る）

7. [ ] **ブロック**：豆腐（灰色の箱）。Physics Material 2D で摩擦・反発を設定
8. [ ] **ステージ1の塔**：豆腐3段＋てっぺんの目印（さくらんぼ）
9. [ ] **成功判定**：目印の落下と傾きの併用〔仮〕。落ちた条件は試作で決める
10. [ ] **失敗判定と即リスタート**：3球使い切って成功しなければ、すぐ最初に戻る
11. [ ] **星評価**：残り球数で1〜3

**完了条件：** ステージ1が、撃つ→崩れる→星が出る→やり直し、と1周できる。

**遊ぶ（最重要）：** 撃って崩れること自体が気持ちよいか。ここで面白くなければ、素材を作る前にコアループへ戻る。

## P3 データ駆動

12. [ ] **食材パラメータ**を ScriptableObject にする（重さ・摩擦・反発・割れる条件）
13. [ ] **ステージ配置**を JSON にする（食材の種類・位置・弾の並び）
14. [ ] ステージ1を JSON から読み込む形に置き換える

**完了条件：** JSON を書き換えるだけで、ステージの配置が変わる。（ここから Claude がステージを量産できる）

## P4 食材と仕掛け（ステージ2・3）

15. [ ] **卵**：脆い。一定の衝撃で割れて、支えが消える
16. [ ] **ステージ2**：卵の土台に、スイカが乗る塔
17. [ ] **シーソー**：HingeJoint2D。スイカの落下で反対側が跳ね上がる
18. [ ] **ステージ3**：シーソーと遠くの塔

**完了条件：** ステージ2・3が、3球の総当たりでも、1球の裏ワザでも解ける。

**遊ぶ：** 「知識ゼロでも総当たりで解けるか」「裏ワザを見つけたら気持ちよいか」を確かめる。大人が会話でヒントを出して進められるか。

## P5 セットの進行と演出（M3：1面クリア）

19. [ ] 1セット＝3ステージの進行。3つ目を終えたら**必ず終わる**画面（「おしまい」）
20. [ ] 演出：着地のスクワッシュ、トドメのスロー（0.3倍速0.5秒）。興奮してOK
21. [ ] アイコン中心のUI（文字なし）
22. [ ] TestFlight に上げて、少人数に渡す

**完了条件：** 子供と大人が、寝る前に3ステージを遊んで、終われる。
