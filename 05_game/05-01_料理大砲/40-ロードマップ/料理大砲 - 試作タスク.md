# 試作タスク（M1〜M3）

親: [[料理大砲 - 00 概要|概要]] ／ マイルストーンは [[料理大砲 - ロードマップ]]

**方針：** 灰色の箱（グレーボックス）で、先に「撃って崩れる気持ちよさ」を確かめる。素材（Meshy）は、M2で面白さを確認してから作る。

**分業：** 実装とデータ追加は Claude、**遊んで判定するのは人間**。連鎖の挙動は人間のプレイテストが必須。各段階の最後に「遊ぶ」を置いてある。

## P0 準備

- [x] Unity のバージョンを決める → 6000.6.10f1（過去の `carchase_game` は 6000.6.10f1 を使用。ノートは Git の履歴 `dc22fdd` に残っている。環境構築とiPadへの入れ方を再利用）
- [x] 2Dプロジェクトを作成（URP の2Dテンプレート）。リポジトリ直下に配置、Hubに登録済み。横画面のみ許可済み。**エディタでの起動・コンパイル確認は未**
- [x] 別リポジトリを作成（`choigames/ryori_cannon`、非公開）。`.gitignore` に素材フォルダを `.meta` ごと入れる。素材のバックアップ先を決める（[[Unity×Git初期設定（調査）]]）
- [ ] iPad 横画面に設定。実機で空のシーンが動く
- [ ] フォルダ構成と命名規則を [[料理大砲 - 命名規則]] に合わせる

**完了条件：** iPad で空のシーンが起動する。

## P1 撃てる（M1：触れる）

1. [ ] **大砲**（コード作成済み・遊んで確認待ち）：左側のドラッグで角度を決める（スナップ。刻みは試作で調整）
2. [ ] **強さボタン**（同上）：右側に大きな3つ（弱・中・強）。選択状態が分かる
3. [ ] **撃つボタン**（同上）：押すと、選んだ角度と強さで弾が飛ぶ
4. [ ] **弾（食材）**（同上）：Rigidbody2D。スイカの灰色の球で、まず飛ぶ
5. [ ] **ガイド**：1バウンドまでの予測軌道線と、着地点の目印
6. [ ] 球数の表示（同上。左上の丸3つ）（3球）と、残り球数が減る

**完了条件：** iPad で、両手で狙って撃てて、ガイドの着地点と実際の着地がほぼ合う。

**遊ぶ：** 子供の指で狙えるか（スナップの刻み、ボタンの大きさ）を確かめる。

## P2 崩せる（M2：ループが回る）

7. [ ] **ブロック**（コード作成済み・遊んで確認待ち）：豆腐（灰色の箱）。Physics Material 2D で摩擦・反発を設定
8. [ ] **ステージ1の塔**（同上）：豆腐3段＋てっぺんの目印（さくらんぼ）
9. [ ] **成功判定**（同上）：いまは「さくらんぼが地面に触れたら成功」だけ。傾きの併用は、試作で必要になってから足す
10. [ ] **失敗判定と即リスタート**（同上。3球目が落ち着いてから1.2秒後に戻る。崩れている最中は撃てない）：3球使い切って成功しなければ、すぐ最初に戻る
11. [ ] **星評価**（同上。星の画面と「もう一回」ボタン）：残り球数で1〜3

**完了条件：** ステージ1が、撃つ→崩れる→星が出る→やり直し、と1周できる。

**遊ぶ（最重要）：** 撃って崩れること自体が気持ちよいか。ここで面白くなければ、素材を作る前にコアループへ戻る。

> [!success] 2026-11-28 試遊の結果
> 最初は「崩れるな」止まり。塔を小さなレンガ積みにして、弾を重くし、揺れ・破片・一瞬の停止・スローを入れたら、「すごく良くなった」。コアループは続行。P3（データ駆動）へ進む。
