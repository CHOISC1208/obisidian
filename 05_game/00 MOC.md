## 新しいゲームを始める手順

1. `_template/` をフォルダごとコピーして `05-0X_<ゲーム名>/` にする（Claude に「新規ゲーム作成: ○○」と頼めば、コピーと `ゲーム名` の置換までやる）。
2. 各ファイル名の先頭 `ゲーム名` を実際の名前に置換する。
3. `ゲーム名 - 00 概要` → `一枚企画` → `面白ポイントとコアループ` の順に Claude と相談しながら埋める。
4. この MOC の一覧に1行足す。

## Claude との進め方

このVaultを開いた Claude Code と会話しながら、ノートを埋めていく。

- **始める：** 「新規ゲーム作成: ○○」と頼む。`_template/` を `05-0X_○○/` に複製し、`ゲーム名` を置換する。
- **続ける：** 「05-0X_○○の続き」と頼む。Claude はまずそのゲームの `00 概要` と `未確定事項` を読んでから再開する。
- **会話ではなくノートに残す。** 決まったことは `決定ログ`（理由つき）、宿題は `未確定事項`、調べたことは `調査メモ` に書く。会話は消えるが、ノートは残る。
- **企画の順序：** 一枚企画 → 面白ポイントとコアループ → スコープ → 素材リスト・技術構成。紙プロトタイプで面白さを確かめてから、素材を作り込む。
- **コード：** 企画が固まったら Unity プロジェクトを**別のGitHubリポジトリ**として作る。企画の正本はこのVaultのまま。コードを書くセッションから企画を読むときは、フォルダを追加するか、要点をリポジトリの `CLAUDE.md` に写す。
- **ずれたら直す：** コードや仕様が企画と変わったら、このVault側も更新する。

## 保存先の方針

| 置くもの | 場所 |
|---|---|
| 企画・設計・決定ログ | この Vault |
| コード・シーン・プレハブ・設定 | GitHub |
| 素材（3Dモデル・画像・音など `Assets/` 内の重いもの） | **Gitに入れない（`.gitignore`）。ローカル保持、バックアップは自己管理** |
| 素材の元データ（PSD・AI生成の元画像など） | Google Drive |
| ランキング・クラウドセーブなどオンライン機能 | Supabase（必要になってから） |

## ルール

- フォルダ番号は並び順で、優先度ではない。
- **文書で決め込みすぎない。** 面白さは紙の上では決まらないので、`一枚企画` と `スコープ` が埋まったら、早めに最小プロトタイプを作って確かめる。
- 決めたことは `決定ログ` に理由つきで残す。
