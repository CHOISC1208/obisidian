## 新しいゲームを始める手順

1. `_template/` をフォルダごとコピーして `05-0X_<ゲーム名>/` にする（Claude に「新規ゲーム作成: ○○」と頼めば、コピーと `ゲーム名` の置換までやる）。
2. 各ファイル名の先頭 `ゲーム名` を実際の名前に置換する。
3. `ゲーム名 - 00 概要` → `一枚企画` → `面白ポイントとコアループ` の順に Claude と相談しながら埋める。
4. この MOC の一覧に1行足す。

## 保存先の方針

| 置くもの | 場所 |
|---|---|
| 企画・設計・決定ログ | この Vault |
| コード・Unityプロジェクト（`Assets/` の本番素材含む） | GitHub（大きい素材は容量を測ってから Git LFS） |
| 素材の元データ（PSD・AI生成の元画像など） | Google Drive |
| ランキング・クラウドセーブなどオンライン機能 | Supabase（必要になってから） |

## ルール

- フォルダ番号は並び順で、優先度ではない。
- **文書で決め込みすぎない。** 面白さは紙の上では決まらないので、`一枚企画` と `スコープ` が埋まったら、早めに最小プロトタイプを作って確かめる。
- 決めたことは `決定ログ` に理由つきで残す。
