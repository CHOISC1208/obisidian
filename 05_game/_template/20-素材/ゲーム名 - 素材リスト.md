# 素材リスト

親: [[ゲーム名 - 00 概要|概要]]

**1素材＝1ノート**で管理し、一覧は Bases（[[素材一覧.base|素材一覧]]）で見る。素材そのものはここに置かない。ノートに書くのはID・ファイル名・置き場所・ライセンスだけ。命名は [[ゲーム名 - 命名規則]] に従う。

## 素材を足す手順

1. `_templates/ゲーム素材テンプレート.md` から、`アセット/` に新しいノートを作る。
2. プロパティを埋める。ノート名は `<ID> <名前>`（例：`CHR-001 主人公`）。
3. 一覧は [[素材一覧.base|素材一覧]] で見る。ビューは4つ：全件 ／ 種別ごと ／ 未完了 ／ ライセンス未確認。

## プロパティ

| プロパティ | 値 |
|---|---|
| `id` | `CHR-001` `BG-001` `UI-001` `SE-001` `BGM-001` `FONT-001` |
| `kind` | キャラ / 背景 / UI / 効果音 / BGM / フォント / その他 |
| `status` | 未着手 / 作成中 / 確認中 / 完了 |
| `source` | 自作 / 購入 / AI / フリー |
| `filename` | Unityに入れるファイル名 |
| `license` | ライセンス・出典URL。**自作以外は必ず書く** |
| `drive` | 元データ（Google Drive）のリンク |
