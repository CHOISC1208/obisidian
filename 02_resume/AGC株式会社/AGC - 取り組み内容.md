# AGC — 取り組み内容

親: [[AGC - 00 概要]] ／ 時系列は [[職務経歴]]

AGC在籍中に担当した案件・成果の一覧。出典はNotion `01_resume` の「取り組み内容」データベース。
各期間の位置づけ・等級・評価は [[AGC - 00 概要]]、年度ごとの目標と評価は [[人事評価_インデックス]] を参照。

## 購買・調達（2011-2017）

| プロジェクト名 | 内容 |
|---|---|
| 購入品単価の削減と競合状態の創出 | 自分の担当課で購入している単価品に対して、新規サプライヤー採用などを含めて競合状態を創出し1000万円/年のCDを実施した |
| 産業廃棄物のコスト削減 | 発生する産業廃棄物の再利用や売却などコストを削減 |
| 在庫の保管方法や保管場所の見直し | 借庫費用や単価を削減した |
| カレット戦力化 | 今までは廃棄していた廃棄物において、場内に新しい設備である分別や洗浄のスキームを導入し原料として戦力化した |
| クラウド受け払いシステムの開発 | 全社的に使用できる、クラウド型の受払いシステムをスクラッチで開発した。要件定義〜開発〜運用まで全て実施 |

## 物流・SCM（2017-2022）

| プロジェクト名 | 内容 |
|---|---|
| 路線便契約の見直し | 新規サプライヤー導入及び競争状態創出によるコストダウン |
| クラウドの競売システムの開発 | BIDのクラウドシステムを作り、①業務の標準化と工数削減 ②業務の質の向上 を実施。要件定義〜開発〜運用まで全て実施 |

| パレット関連費用の削減 | 外注に頼りっきりだった作業を場内に持ち込む事によって、物流費や販管費用を削減した |
| 物流伝票の電子化 | 社内外で利用していた紙の物流伝票を電子化し、見える化と作業効率の向上を実施した。要件定義〜開発〜運用まで全て実施 |
| 事故撲滅PJT | 事故が多発する工場においてデジタル安全スキームを導入し事故を０にした |
