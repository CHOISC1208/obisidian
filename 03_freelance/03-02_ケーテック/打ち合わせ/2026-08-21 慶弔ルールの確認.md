# 2026-08-21 慶弔ルールの確認

親: [[00 MOC|ケーテック株式会社 MOC]]

出典: `docs/hearing/2026-08-21_keicho-rule-clarification.md`。
先方からの実装タスクブリーフ（**慶弔見舞金規程 令和5年10月1日施行**の内容を含む）＋
チャット上での確認事項。

> [!important] 最大級のブロッカーが解消した回
> 2026-08-07 から★ブロッカーだった「慶弔見舞金規程（種別×続柄→金額・特別休暇日数の一覧）の提供」が
> ようやく届いた。[[申請ポータル - APP No.02 慶弔連絡]]を**全面改訂**した。

## 提供された規程の要旨

### 対象者区分

| 区分 | 対象 |
|---|---|
| A | 正社員・嘱託員（勤続年数条件なし） |
| B | パート・契約社員 勤続3年以上（**Aと同額**） |
| C | パート・契約社員 勤続3年未満（制度により支給なし・減額） |

### 制度

| 制度 | 条項 | 本ポータルでの扱い |
|---|---|---|
| 結婚祝金 | 第4条 | ○ |
| 出産祝金 | 第5条 | ○ |
| 弔慰金 | 第6条 | ○ |
| 傷病見舞金 | 第7条 | ○（業務上/業務上以外で金額が変わる） |
| 特別加算金 | 第2条2項 | ○（**人事起票**） |
| 慰労金 | 第8条 | **✕ スコープ外**（定年退職者への品物・花束の現物支給） |
| 社葬・葬祭料等 | 第6条2項 | △ **起票のみ**（都度審議のため金額決定はフロー外） |

## 判明した最重要事項

> [!important] 元Excelの要件の半分は存在しなかった
> 元Excelには「**条件分岐2つ（金額・休暇日数）**」と書かれていた。
> しかし**規程に特別休暇の定めが無かった**。
>
> → `SpecialLeaveDays`（特別休暇日数）列を**削除**した。
>
> ヒアリングの回答や依頼書の記述が、必ずしも実際の規程・実データと一致しないことの実例。

## 決定事項（7つ）

| # | 決定 |
|---|---|
| 1 | 勤続年数の起算・カウントは**自動計算せず、申請者の自己申告**（手入力） |
| 2 | 結婚祝金の「入社後2回目以降」は自己申告のチェック。**復縁時の取り扱い（支給対象外）は SPFx で判定せず**、承認者・フロー側の運用に委ねる |
| 3 | 弔慰金の「実祖父母 同居/別居」は自己申告。承認者が必要と判断した場合のみ追加確認 |
| 4 | 社葬・葬祭料等は「社葬等協議事項」として**起票のみ**。`IsUnderDeliberation=true` のまま `PlannedAmount` は確定させない |
| 5 | 特別加算金は**人事側が起票**（本人からの申請フローではない） |
| 6 | 慰労金は本ポータルのスコープ外（総務の別タスク） |
| 7 | **承認段階は第一段階のみ。** 金額の大小によらず第二段階承認は設けない |

## このリポジトリ固有の事情による読み替え

> [!info] ブリーフが `main` ブランチ（中央承認エンジン方式）の前提で書かれていた
> ブリーフには `ApprovalTransactions` の参照や `RequestTypeSettings` の第二承認者を空欄にする指示が
> 書かれていたが、どちらも簡易承認方式では**撤去済み**の概念だったため、実装では無視した。
> → [[申請ポータル - 承認方式（簡易承認への転換）]]

| ブリーフの記載 | 実装 |
|---|---|
| `EmploymentType` は「従業員マスタ参照」 | **従業員マスタが存在しないため自己申告の Choice 列**として実装（ユーザー確認済み） |
| `ApprovalTransactions` 参照 | 無視（存在しない） |
| `RequestTypeSettings` の第二承認者設定 | 無視（存在しない）。決定事項7で「第一段階のみ」となり実質不要 |

`KeichoMaster`（慶弔マスタ）は規程の内容に合わせて**全面再設計**した。
実際の算出ロジック（マスタ参照・結婚祝金の半額計算等）は Power Automate フロー本体が担う想定で、
SPFx 側は `PlannedAmount` / `IsUnderDeliberation` をフロー設定列として隠すところまでを実装した。

## 規程との突き合わせで新たに判明した仮置き・未解消事項

| # | 内容 | 状態 |
|---|---|---|
| 1 | **傷病見舞金は業務上/業務上以外で金額が変わる**（規程第7条）が、ブリーフの列設計表にこの軸が無かった | `IsWorkRelated`（業務上の傷病）列を**こちらの判断で追加**。**要ユーザー確認** |
| 2 | 結婚祝金の子女は第一子(10,000円)とそれ以外(5,000円)で金額が異なるが、`TargetPerson` の選択肢（ブリーフ指定）が「子女」一本化のため区別できない | マスタは**第一子額のみ**登録し、それ以外は人事の手動調整に委ねる。**未解消** |
| 3 | 傷病見舞金の支給条件「休業4週間以上」の自動判定 | **行わない**（承認者の目視判断に委ねる） |
| 4 | `EmploymentType`（自己申告）の誤申告リスク | `Approver` 列の誤選択と同様、**承認者確認に依存する** |

> 追認をもらう必要がある。→ [[05 要確認事項]]
