# 制作ステップ（案）

親: [[00 MOC|game MOC]]

> [!warning] 叩き台
> 決まったこと: 「ついてきて」型（案内役についていき、置いていかれずにゴールに着けば勝ち）／幼児〜小学生・キーボード／まず自分用。
> 置いていかれたときは案内役が待ってくれる（負けなし）。案内役の姿・速さ・道の形はまだ未定。詳しくは [[_未確定事項]]。

## ステップ

| # | 内容 | できあがりの目安 |
|---|---|---|
| 1 | 地面とカメラを置く | 平らなステージが見える |
| 2 | プレイヤーを置く（Cube/Capsule でよい） | シーン上に立っている |
| 3 | Input System で移動 | 矢印キー／WASD で動く（`InputSystem_Actions` を利用） |
| 4 | 案内役を置き、道に沿って動かす | 案内役がウェイポイントをたどってゴールへ進む |
| 5 | 距離の判定とゴール | 離れすぎたら案内役が止まって待ち、追いつくと進み出す。ゴールに着くと勝ち（負けなし） |
| 6 | UI（スコア・リトライ） | 結果が表示され、やり直せる |
| 7 | 見た目と音 | 色・ライト・効果音で遊べる状態 |
| 8 | ビルド | Mac で実行できる |

## 進め方のルール

- 各ステップ終わりでコミットし、`main` へプッシュする。
- Unity の `.meta` ファイルは必ずセットでコミットする。
- 変更はシーンを保存してから確認する。
