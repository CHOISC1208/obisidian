# 制作ステップ（案）

親: [[00 MOC|game MOC]]

> [!warning] 叩き台
> ゲームの中身（誰が誰を追うか、勝ち負け、対象年齢）がまだ決まっていない。以下は一般的な順序の案で、[[_未確定事項]] が埋まったら直す。

プロジェクト名 KidsChaseGame から「子ども向けの追いかけっこ」を想定している。

## ステップ

| # | 内容 | できあがりの目安 |
|---|---|---|
| 1 | 地面とカメラを置く | 平らなステージが見える |
| 2 | プレイヤーを置く（Cube/Capsule でよい） | シーン上に立っている |
| 3 | Input System で移動 | キーボード／パッドで動く（`InputSystem_Actions` を利用） |
| 4 | 追いかけてくる敵を置く | 敵がプレイヤーへ向かって動く |
| 5 | 当たり判定と勝ち負け | つかまったらゲームオーバー、逃げ切ったらクリア |
| 6 | UI（スコア・リトライ） | 結果が表示され、やり直せる |
| 7 | 見た目と音 | 色・ライト・効果音で遊べる状態 |
| 8 | ビルド | Mac で実行できる |

## 進め方のルール

- 各ステップ終わりでコミットし、`main` へプッシュする。
- Unity の `.meta` ファイルは必ずセットでコミットする。
- 変更はシーンを保存してから確認する。
