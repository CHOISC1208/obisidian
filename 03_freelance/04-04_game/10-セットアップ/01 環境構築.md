# 環境構築の記録

親: [[00 MOC|game MOC]]

Apple Silicon の Mac で Unity の 3D ゲーム開発環境を整えた手順と、つまずいた点。

## 手順

1. Homebrew で `unity-hub`（4.0.1）をインストール。
2. Homebrew で `dotnet-sdk`（11.0.100）をインストール。pkg インストーラが `sudo` のパスワードを求めるため、**自分のターミナルで** `brew install --cask dotnet-sdk` を実行した。
3. Unity Hub で Unity ID にログインし、Preferences > Licenses で Personal（無料）を有効化。
4. Unity CLI（1.0.1）をインストール: `curl -fsSL https://unity.com/install.sh | bash`
5. Unity エディタ 6000.6.10f1 をインストール。
6. `unity projects create` で 3D（URP）プロジェクトを作成し、リポジトリ直下に配置。
7. 公式の `.gitignore`（`.DS_Store` を追加）を置き、GitHub の `main` へプッシュ。
8. Unity Hub に「ディスクからプロジェクトを追加」で登録し、SampleScene が開くことを確認。

## つまずいた点

> [!warning] Unity Hub 4.0.1 では `-- --headless` が使えない
> `-- --headless releases` や `install` は、別アプリの **Unity CLI**（`unity` コマンド）に移っている。Hub のメッセージに案内が出る。

> [!warning] 6000.0 系は Personal では入れられない
> 6000.0.86f1 は「延長 LTS」の権限が必要で失敗した。Personal ライセンスで入れられる範囲から選ぶ必要がある。
> 6000.3 LTS（6000.3.29f1）を選んだが、Hub 側で 6.6 のインストールが先に走っていて **インストールロック**（`INSTALL_LOCK_BUSY`）で入らなかった。結果として 6000.6.10f1（LTS ではない）で進めた。

> [!warning] プロジェクトは「リポジトリ直下」に置く
> `unity projects create` はプロジェクト名のフォルダを作るため、そのままだと `リポジトリ/KidsChaseGame/` という入れ子になる。`Assets` などをリポジトリ直下へ移した。移した後は、Hub の登録を付け替える必要がある（古いパスは「プロジェクトが見つかりません」と出る）。

> [!warning] Hub の「新規プロジェクトを作成」を押さない
> 既存プロジェクトを開くときは「ディスクからプロジェクトを追加」。新規作成を押すと、別のプロジェクト（とクラウドプロジェクト）ができてしまう。

## 確認したこと

- `Packages/manifest.json` に `com.unity.inputsystem` 1.20.1 が入っている（追加不要）。
- `.gitignore` で `Library`・`Logs`・`UserSettings` が無視される。
- SampleScene は Main Camera・Directional Light・Global Volume だけの空シーンで、コンパイルエラーなし。
