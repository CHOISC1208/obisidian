# プロジェクト構成と追加のしかた

親: [[00 MOC|game MOC]] ／ 仕様は [[01 ゲーム仕様と画面の流れ]]

## 方針

- ステージ・キャラのPrefab・メニュー画面は**コードから自動生成**する。シーンや Prefab を手で組まない。
- 生成は `Tools > KidsChase > Build All`。キャラやコースを足したら必ず実行。
- エディターの再生ボタンは**常に Title から始まる**（`Tools > KidsChase > Play From Title` でオフにできる）。

## スクリプト（Assets/Scripts）

| ファイル | 役割 |
|---|---|
| `CharacterRoster` | キャラ一覧、選択中のキャラ、10マスの配置 |
| `StageRoster` | コース一覧（道の形・色・難易度・岩の間隔）、ベストタイム保存 |
| `GameManager` | レース進行（紹介→ランプ→スタート→ゴール）、ゴール画面 |
| `CarController` | プレイヤーの移動（Rigidbody）、ぶつかり、岩との接触 |
| `GuideController` | 先導車の走り、待つ・急加速・幅寄せ |
| `RockDropper` / `Rock` | 先導車が岩を落とす / 岩の落下と当たり判定 |
| `PlayerAvatar` / `CharacterRunner` | 選んだキャラを出す / 走りの動き・足音のきっかけ |
| `CameraFollow` | 追いかけカメラ、スタート前の紹介カメラ |
| `TouchControls` | スマホの画面ボタン（タッチ画面のときだけ表示） |
| `TitleScreen` / `CharacterSelectScreen` / `StageSelectScreen` | メニュー画面（IMGUI） |
| `Ui` | 文字・四角・線を描く道具（画面の高さ720基準） |
| `AudioManager` / `ProceduralAudio` | 音の管理 / コードで音を作る |

## エディター用（Assets/Editor）

| ファイル | 役割 |
|---|---|
| `BuildAll` | 全部まとめて生成 |
| `CharacterPrefabBuilder` | FBX から `Resources/Characters/*.prefab` と岩の Prefab を作る |
| `PrototypeSceneBuilder` | コースごとのシーン（道・木・ゴール・プレイヤー・先導車）を作る |
| `MenuSceneBuilder` | Title / CharacterSelect / StageSelect を作り、Build Settings の順番を決める |
| `BuildIOS` | iPad / iPhone 用の Xcode プロジェクトを `Builds/iOS` に出す |
| `PlayFromTitle` | 再生を Title から始める |

## 追加のしかた

### キャラを足す
1. `Assets/Models/名前/` に `名前.fbx` と、`名前_albedo.png` `_normal.png` `_metallic.png` `_roughness.png`（あれば `_emission.png`）を置く。Meshy の zip は、ファイル名をこの形に直して入れる。
2. `CharacterRoster.cs` の `Entries` に1行足す（キー・表示名）。`SlotEntry` の `-1`（「？？」）を、そのキャラの番号に変える。
3. `CharacterPrefabBuilder.cs` の `Settings` に（キー・高さ・向きの補正）を足す。
4. `Build All` を実行。

> [!warning] Meshy の画像の落とし穴
> ダウンロードした `.png` の中身が WebP や JPEG のことがある（SpongeBob で発生）。Unity が読めず**真っ白**になる。`file` コマンドで確認し、PNG に変換する。8192px などは 4096px に縮める。

### コースを足す
1. `StageRoster.cs` の `Stages` に1つ足す（シーン名・難易度・道幅・先導車の速さ・色・木の数・制御点・岩の間隔）。
2. `Build All` を実行（シーンの生成と Build Settings への追加も自動）。

### BGM を足す
- 音楽ファイルを `Assets/Resources/Bgm/` に入れるだけ。ランダムの候補に入る。

## 注意

- 先導車は、プレイヤーが70m以上離れると岩を落とさない。
- キャラの Prefab は「足元が原点・前が +Z」に正規化してある。FBX 自体の拡大率（100倍など）は残して、掛け算で大きさを合わせる（上書きすると小さくなって見えなくなる）。
- 大きなファイル（モデル・画像）は Git LFS で管理（`.gitattributes`）。SpongeBob の FBX は約100MB。
