# プラットフォーム選定の判断軸

新しい要件を [[choi-tone]] と [[green-earth-platform]] のどちらに載せるか。

```
新しい要件が来た
│
├─ Q1. 目的は「数値・記録をとにかく集める」ことだけか？
│      （複数拠点・関係者が入力するだけで、入力後の加工・計算は不要）
│      → Yes: choi-tone
│      → No : Q2へ
│
├─ Q2. 業務ロジック（原価計算・在庫増減・生産計画・帳票連携など）が絡むか？
│      → Yes: green-earth-platform
│      → No : Q3へ
│
├─ Q3. マルチテナント（複数の組織・拠点を横断して同じ仕組みを使い回す）か？
│      → Yes: choi-tone
│      → No : Q4へ
│
└─ Q4. MFA必須クラスの機密性・厳格な権限管理が要るか？
       → Yes: green-earth-platform
       → No : 要相談
```

**一言でいうと**: 「集めるだけ」で完結するか（→ choi-tone）、「集めたデータを使って何かを動かす／計算する」必要があるか（→ green-earth-platform）。

| 判断軸 | choi-tone が向く | green-earth-platform が向く |
|---|---|---|
| 目的 | 数値・記録を集めることがゴール | 集めたデータで業務を回す・判断する |
| ユーザー | 多拠点・多関係者が入力するだけ | 社内の業務担当者が運用する |
| データ構造 | 単純なテーブル1つで完結 | 複数テーブルが連携する業務フロー |
| ロジック | ほぼCRUD | 計算・集計・分析・帳票連携 |
| セキュリティ | 社内Googleアカウントで十分 | MFA必須・アカウントを厳格に管理 |
| リリース速度 | 小さい変更を頻繁に | 業務影響が大きいので慎重に |
