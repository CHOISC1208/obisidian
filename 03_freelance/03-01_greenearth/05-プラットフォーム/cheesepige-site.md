# cheesepige-site

> CheesePige.jp の顧客向けサイト。自社でコンテンツ更新できることが最重要要件。

⚠️ **2026-09時点で大きく変更する可能性あり。** 現行の状態はスナップショットとして残し、変更内容は下部に記録する。

## 位置づけ

[[green-earth-platform]] と同じ Supabase プロジェクト内の `cheesepige_site` スキーマを使うが、GitHubリポジトリは別。

**厳守**: サイト側のマイグレーションから `public` スキーマや社内プラットフォームのテーブルを絶対に触らない。

## デザイン方針（2026-07 決定分）

- 構造は Apple 的（1画面1メッセージ、余白、スクロール駆動のナラティブ、セクション背景の交互）
- タイポグラフィは柔らかい丸ゴシック。見出し Zen Maru Gothic ／ 本文 Zen Kaku Gothic New
- パレット: クリーム／生成り／テラコッタ／チーズイエロー／ピンク。純黒ではなくココア
- **主アクセントはチーズイエロー `#F0B429`**。クリーム背景＋テラコッタはAI生成にありがちな配色なので、イエローを主役にしてブランド固有性を出す
- モーションは CSS + Intersection Observer のみ。アニメーションライブラリ禁止、スクロールジャック禁止
- 動画素材がないため、動画枠は Ken Burns 効果の写真で代替
