# プラットフォームの機能説明・追加機能の検討（2026-09-28）

親: [[00 サマリー|2026-09-28 サマリー]] ／ 関連: [[platform - 00 概要]]

> [!info] このノートについて
> 2026-09-28打ち合わせ、項目5の詳細。段階1〜5で完成した統合コンソール全体を一通り説明し、欲しい追加機能がないかを確認する回。**ダッシュボードは特に詳しく説明する。**

## 全体構成（モジュール軸）

画面の入口はモジュール単位：**ダッシュボード／受注／入出荷／帳票／マスタ**。データの持ち主（スキーマ・権限）は業務単位（inventory／ec／core）で、URLには出さない → [[platform - 00 概要]]。

## ダッシュボード（詳しく説明する）

| 画面 | 内容 |
|---|---|
| 受注残ボード | SKUごとの出荷予定の可視化 |
| 経営サマリー | easyECSで受けている楽天・Amazon・Yahoo!・au PAYなどの売上を前年・過去の年と比較（受注日／出荷予定日で切替。税抜・送料なし、キャンセル除く） |
| 商品・モール | 商品（シリーズ／SKU）ごとの売れ行き、モールごとの平均単価、新規・リピーター別 |
| 季節・予約進捗 | 品目ごとに今年と前年の受注（予約日）・出荷予定を同じ月日で比較 |
| 分析 | 売上が伸びた理由（前年同期比較）・季節を除いたトレンド・品目の位置づけ（社内版PPM・ABC）・併売 |
| 商品ポートフォリオ | 商品シリーズを「花形・金のなる木・問題児・負け犬」に分け、年ごとの動きを追跡 |
| 商品カルテ | シリーズ・SKUごとの年別・月別売上、モール別の売れ方、品目の中での位置づけ |
| 競合分析（楽天） | キーワードで楽天市場を検索し、価格・レビュー数を見る。検索結果を履歴として残すので値動きを追える |

> [!warning] ダッシュボードの前提：easyECSに入っているデータしか見えない
> 経営サマリー以下の売上系ダッシュボードは、毎晩の同期（`scripts/sync-easyecs-sales`）でeasyECSから写したデータだけを集計している。**ふるさと納税・自社EC（Shopify）・実店舗・KRKは含まれない。** どのチャネルを優先的にeasyECSへ入れるかは別途相談する → [[テーマ1 - 受注チャネル統合の進捗確認]]

## 受注（受注チャネルの取得・取り込み）

- 7チャネル（楽天・Amazon・Yahoo・au PAY・Shopify・Temu・LINEギフト）の受注取得
- MDC取り込み／その他受注取り込み（手動受注の取り込み）

## 入出荷・帳票（仕入側。Airtable代替）

## マスタ

- 取引先／商品・原価／規格マスタ（inventory側）
- SKU対応表（MDC／その他）／商品シリーズ／チャネル認証情報（ec側）

## 確認したいこと

- 一通り説明した上で、**欲しい追加機能がないか**
