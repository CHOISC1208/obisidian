# 統合コンソール デザイン指示書（v2）

親: [[platform - 00 概要]] ／ レビュー: [[platform - 07 デザイン指示書レビュー]] ／ 設計方針: [[platform - 05 統合方針（決定事項と設計）]]

> [!info] このノートについて
> 統合コンソールのデザインの**正本**。v1（2026-09-14 ちぇる作成）に、[[platform - 07 デザイン指示書レビュー]] の指摘と、それを受けた決定を反映したのが v2。
> 色の値はすべて計算で検証済み（コントラスト比は WCAG 2.x の式）。v1 との差分は末尾の「改訂履歴」にある。

対象：緑茶園グループ向け 受注・入出荷・帳票 統合コンソール（Next.js 16 + Supabase + Tailwind CSS v4 + shadcn/ui）
用途：Claude Codeへそのまま渡す実装ガイドライン。`ryokuchaen-platform` の CLAUDE.md にこの内容を要約して転記すること。

---

## 1. 前提・方針

- 社内業務ツールであり、来訪者向けのマーケティングサイトではない。**視認性・情報密度・現場での見やすさ**を最優先し、装飾のための演出は入れない。
- それでいて「緑茶園グループの標準ツールだ」と一目で分かる、一貫した個性を持たせる。
- 起点は「緑茶」という具体的な題材。一般的な「エコ・オーガニック」のイメージする鮮やかな黄緑ではなく、**煎茶・深蒸し茶の落ち着いた深緑**を基準にする。
- shadcn/uiのデフォルトテーマ（zinc/slate系グレー、汎用的な丸角・影）はそのまま使わない。CSS変数を上書きする形で本指示書のトークンを適用する。
- **色は HEX を正本とする。** HSL などへの変換は挟まない（変換すると丸めで色がずれるため）。

## 2. カラートークン

基準となる緑は「深蒸し煎茶」の色。背景は白でもクリーム色でもなく、**茶器の陶器・和紙をイメージした淡いセージグレー**にする（暖色のクリーム地は生成AIデザインで頻出するため避ける）。

| 役割 | 名称 | HEX | 使い方 |
|---|---|---|---|
| 背景 | 陶器グレー | `#F2F3EF` | ページの地。茶器・和紙をイメージした、緑みを帯びた淡いグレー |
| 前景（本文） | 墨緑 | `#1F2A22` | 純黒ではなく緑を帯びた濃色。データ表でも読みやすい濃さ |
| プライマリ | 深蒸し茶 | `#2F5233` | ボタン・主要アクション・**選択中の表示**・**リンク** |
| プライマリ前景 | — | `#F2F3EF` | プライマリの地に乗る文字色 |
| アクセント | 新茶若葉 | `#7A9B76` | **ホバーの地色だけ**に使う。選択中の表示には使わない |
| アクセント前景 | — | `#1F2A22` | アクセントの地に乗る文字色 |
| セカンダリ | 薄茶灰 | `#D8DED2` | 区切り、非アクティブ項目の地色。文字色には使わない |
| ミュート | 薄墨灰 | `#E8EAE3` / 文字 `#5B6358` | 補足情報、プレースホルダー |
| ボーダー | 薄茶灰 | `#D8DED2` | 区切り線（hairline） |
| 入力欄の枠 | 灰緑 | `#848D7F` | 入力欄・セレクト・テキストエリアの枠 |
| フォーカスリング | 焙じ緑 | `#3B5D42` | フォーカス時のアウトライン（アクセシビリティ） |
| 警告 | 焙じ茶 | `#B8863B` | 警告の**地色**（バッジ・注意帯）。上に乗る文字は墨緑 `#1F2A22` |
| 警告（文字・アイコン） | 濃い焙じ茶 | `#855F27` | 警告を**文字やアイコン**で示すとき |

### 2.1 コントラスト（検証済みの組み合わせ）

ウェイトは 400/500 のみで本文は 14px のため、**文字はすべて 4.5:1 以上**、UI部品の境界・状態を示す色は 3:1 以上を基準にする。

### 2.2 使い方のルール

- **警告色 `#B8863B` を文字・アイコンに使わない**（背景上 2.89）。文字とアイコンは `#855F27`
- **選択中はプライマリで示す。** アクセントはホバーの地色だけ。**アクセントの地にプライマリ色の文字を載せない**（2.85）
- **リンクはプライマリ色。** ただし本文との色の差が 1.68 しかないので、**文中のリンクには下線を付ける**。表のセルやナビゲーションなど、位置でリンクと分かる箇所は下線なしでよく、ホバーで下線を出す
- **入力欄は常に背景色 `#F2F3EF` で塗る。** 透明のままミュート地に置くと枠が 2.84 で足りない
- **フォーカスリングは不透明の 2px にし、要素との間に背景色で 2px の隙間を空ける。** 半透明にすると 2.25、プライマリのボタンに直接接すると 1.19 で見えなくなる
- **状態を色だけで示さない。** バッジには必ず文言を入れる
- **印刷時は背景を白にする。** 陶器グレーの地のまま印刷すると帳票に色が乗る（本文 on 白 14.87）

### 2.3 グラフの系列の色（2026-09-17 追加）

売上ダッシュボードの品目別の積み上げグラフのために追加した。**2〜2.2 のトークンだけでは品目を塗り分けられなかった**（緑系が多く、新茶若葉と焙じ茶は色覚の違いによっては見分けにくい。dataviz の検証スクリプトで不合格）ため、グラフの系列だけに使う色を足す。ちぇるの承認を得て採用。

| 順 | 名称 | HEX | CSS変数 |
|---|---|---|---|
| 1 | 緑 | `#2F8F5B` | `--chart-1` |
| 2 | 藍 | `#5470C6` | `--chart-2` |
| 3 | 焙じ茶の橙 | `#D9772F` | `--chart-3` |
| 4 | 藤紫 | `#B0569E` | `--chart-4` |
| 5 | 山吹 | `#D6A21E` | `--chart-5` |
| 6 | 青緑 | `#0096A8` | `--chart-6` |
| その他 | 灰 | `#B4BAAF` | `--chart-other` |

- **検証**：背景 `#F2F3EF` に対して、明るさの帯・彩度・隣り合う色の見分けやすさ（1型・2型・3型の色覚、通常の色覚）をすべて通過（隣り合う色の最小の差は ΔE 18.7）。「その他」の灰は彩度が低いのが目的なので、彩度の項目だけ対象外
- **この順に割り当て、7つ目以降は「その他」にまとめる。** 色を増やさない
- **色は系列（品目）に付け、順位に付けない。** 指標や期間を切り替えても同じ品目は同じ色
- **背景とのコントラストが 3:1 に届かない色がある**（橙 2.84、山吹 2.08）。**グラフには必ず数値の表を添え、凡例は積む順と同じ並びにする**
- **文字色・地色・状態（成功・警告・エラー）には使わない。** 状態の色は 2 のトークンのまま
- 積み上げの系列の間は背景色の 2px の隙間で区切る

## 3. タイポグラフィ

- フォントは**1系統のみ**（Noto Sans JP。欧文・数字はNoto Sans JPのラテン部分をそのまま使用、見出し用の別書体は用意しない）。業務ツールなので複数書体で個性を出す必要はない。
- ウェイトは400（本文）・500（見出し・強調）の2段階のみ。600/700は使わない。
- 数値カラム（受注金額・数量・単価など）は`font-variant-numeric: tabular-nums;`を指定し、桁を揃える。これは装飾ではなく帳票的な実用要件。
- 見出しに単語だけ色やイタリックで強調する、ラベルを全て大文字にする、といった処理はしない（生成AIデザインの典型的な"わざとらしさ"のため）。
- 日本語フォントは容量が大きいので、読み込み方（`next/font` のサブセット指定など）は実装時に実測して決める。

| 用途 | サイズ | ウェイト |
|---|---|---|
| ページ見出し(h1) | 20px | 500 |
| セクション見出し(h2) | 16px | 500 |
| 本文 | 14px | 400 |
| 補足・キャプション | 12px | 400 |
| データテーブル | 13px | 400（数値は tabular-nums） |

## 4. レイアウト・構造

```
┌──────────────────────────────────────────────────────┐
│ ヘッダー（52px）                                        │
│  モジュールタブ：ダッシュボード / 受注 / 入出荷 / 帳票 / マスタ  ユーザーメニュー │
├────────────┬─────────────────────────────────────────┤
│ サイドバー    │ コンテンツ                                │
│ 240px       │ 一覧 → 詳細の2ペイン、または単一ビュー         │
│ ⇔ 56px      │                                         │
│（折りたたみ）  │                                         │
│ 選択中モジュール│                                         │
│ の項目のみ     │                                         │
│（権限で絞込）  │                                         │
└────────────┴─────────────────────────────────────────┘
```

- ヘッダーとサイドバーの境界、サイドバーとコンテンツの境界は**1pxのhairline border**（`#D8DED2`）のみ。影（box-shadow）は使わない。
- カード・パネルは意味の階層によって角丸を使い分ける。全部同じ角丸にしない：
  - パネル・カード：8px
  - ボタン・入力欄：6px
  - バッジ・ピル（ステータス表示）：完全な丸（9999px）
- コンテンツを何でもかんでも「白背景・丸角・影」のカードで囲まない。一覧画面はテーブルをそのまま背景に置き、区切りはhairline borderで十分。カードは「独立した操作パネル」など、本当に囲む意味がある箇所だけに使う。
- 余白は8pxの倍数で統一（8 / 16 / 24 / 32px）。

### 4.1 ヘッダー

- 左にモジュールタブ、右にユーザーメニュー
- **タブは、そのモジュールの画面を1つでも使える人にだけ出す**
- 選択中のタブはプライマリで示す（文字色＋下辺の線など。アクセントは使わない）
- ユーザーメニュー：ログイン中のメールアドレス、**権限設定（superuser のみ表示）**、ログアウト

### 4.2 サイドバー

- 選択中モジュールの項目だけを出す。権限の無い項目は出さない
- **折りたたみあり**：240px ⇔ 56px
  - 畳んだときはアイコンだけにし、項目名はツールチップ（`title`）で出す
  - 開閉の状態はブラウザごとに覚える
  - 自分で開閉したことがなければ、幅 1024px 未満の画面では畳んだ状態から始める
- アイコンは lucide-react（shadcn/ui の既定と同じ）
- 選択中の項目：プライマリの地＋プライマリ前景
- ホバー：アクセントの地＋墨緑の文字
- 項目が多いモジュールは見出しでグループに分ける（見出しは 12px・ミュート文字。大文字化しない）
- **ホーム（`/`）ではサイドバーを出さない**。モジュールはヘッダーのタブから選ぶ（2026-09-14 決定）

### 4.3 モジュールと画面の割り当て

**画面の入口（ヘッダーのタブ・サイドバー・URL）はモジュールで切り、データの持ち主（DBスキーマ・`lib/`・権限キー）は業務（`inventory`／`ec`／`core`）で切る。**
そのため、1つのモジュールに仕入と EC の画面が混在してよい。URL に `inventory`・`ec` は出さない。Route Handler（`/api/...`）は画面ではないので、データの持ち主側（`/api/inventory/...`・`/api/ec/...`）に置く。

URL の英語名は仮。

## 5. モーション

- ページ遷移・要素の出現に対するfade-in/slide-upなどの演出は入れない。
- モーションは「ユーザーの操作に応答する」場合のみ：サイドバー項目のホバー、ボタンのpress状態、サイドバーの開閉、保存中のローディングインジケータなど。
- `prefers-reduced-motion`を尊重する（shadcn/ui のダイアログ・ドロップダウンの開閉アニメーションも含めて止める）。

## 6. CSS変数（Tailwind CSS v4 ＋ shadcn/ui、`globals.css` に適用）

Tailwind v4 と現行の shadcn/ui では、`:root` の変数に**色そのもの**を書き、`@theme inline` で Tailwind の色名に対応づける（v1 の `129 27% 26%` のような成分だけの書き方は v3 時代の形式で、v4 では色として効かない）。
shadcn/ui が導入時に生成する `globals.css` の変数名・並びは CLI のバージョンで変わりうるので、**生成されたものを基に、値だけ下記に置き換える**。

```css
:root {
  --radius: 0.5rem;                   /* 8px：パネル・カード */

  --background: #F2F3EF;              /* 陶器グレー */
  --foreground: #1F2A22;              /* 墨緑 */

  --card: #F2F3EF;
  --card-foreground: #1F2A22;
  --popover: #F2F3EF;
  --popover-foreground: #1F2A22;

  --primary: #2F5233;                 /* 深蒸し茶：ボタン・選択中・リンク */
  --primary-foreground: #F2F3EF;

  --secondary: #D8DED2;               /* 薄茶灰 */
  --secondary-foreground: #1F2A22;

  --muted: #E8EAE3;                   /* 薄墨灰 */
  --muted-foreground: #5B6358;

  --accent: #7A9B76;                  /* 新茶若葉：ホバーの地色のみ */
  --accent-foreground: #1F2A22;

  --destructive: #9C4A3C;             /* 赤土 */
  --destructive-foreground: #F2F3EF;

  --warning: #B8863B;                 /* 焙じ茶：地色 */
  --warning-foreground: #1F2A22;
  --warning-emphasis: #855F27;        /* 警告の文字・アイコン */

  --success: #46724C;                 /* 若葉緑 */
  --success-foreground: #F2F3EF;

  --border: #D8DED2;                  /* 区切り線 */
  --input: #848D7F;                   /* 入力欄の枠 */
  --ring: #3B5D42;                    /* 焙じ緑 */

  --sidebar: #F2F3EF;
  --sidebar-foreground: #1F2A22;
  --sidebar-primary: #2F5233;
  --sidebar-primary-foreground: #F2F3EF;
  --sidebar-accent: #7A9B76;
  --sidebar-accent-foreground: #1F2A22;
  --sidebar-border: #D8DED2;
  --sidebar-ring: #3B5D42;
}

@theme inline {
  --radius-sm: calc(var(--radius) - 4px);
```

### 6.1 shadcn/ui の部品ごとの上書き

| 部品 | 上書きする点 |
